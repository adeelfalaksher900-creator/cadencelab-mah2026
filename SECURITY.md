# Security

CadenceLab is a static web application with browser-local audio inference. Read [the security boundary and verification notes](docs/SECURITY.md) before treating local processing as a broader privacy guarantee.

Do not upload private recordings, credentials or exploit details to a public issue. If GitHub private vulnerability reporting is available, use the repository Security tab. Otherwise open a minimal issue requesting a private reporting channel without disclosing sensitive details. Do not test unrelated users or third-party infrastructure.

This hackathon version has no maintained-version support guarantee. Fixes should include a clear reproduction, the affected boundary and a focused validation. Dependency audits and automated accessibility checks do not constitute a security certification.
